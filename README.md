MediQueue 🏥

Hospital Token Booking and Queue Management Application

MediQueue is a Flutter-based application designed to simplify hospital visits through digital token booking and queue management.

🚀 Features

- Book hospital tokens.
- View the number of tokens ahead.
- Check estimated waiting time.
- View queue status.
- Simple and user-friendly interface.

🛠️ Technologies Used

- Flutter
- Dart
- Android Studio
- Visual Studio Code

🎯 Objective

To reduce waiting time and make hospital queue management easier for patients.

Currently under development.
